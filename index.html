An interactive first pass

Quantum physics starts when probability gets a phase.

Classical probability tells us how often outcomes happen. Quantum mechanics adds a hidden bookkeeping layer: amplitudes can point in different directions before becoming probabilities.

Course map

Start with the mathematical spine.

The project is organized like a book-length undergraduate quantum mechanics course, but with original explanations and interactive checks. The aim is not only to recognize the words, but to learn how the equations constrain physical predictions.

The central move is always the same: choose a state space, write the Hamiltonian, solve or approximate the eigenvalue problem, and translate amplitudes into probabilities.

\[ i\hbar\frac{\partial}{\partial t}\Psi(x,t)=\hat H\Psi(x,t) \] \[ \hat H = -\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf r) \]
